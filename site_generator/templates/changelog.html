Changelog

Each version of the data is numbered major.minor.patch:

  • major: a change to the database schema;
  • minor: data added or newly computed;
  • patch: a correction to existing values.

Labels are permanent from version 1.0.0 on. To cite the data, give the version you used and, where it has one, its DOI, which points to an archived copy of that version.
