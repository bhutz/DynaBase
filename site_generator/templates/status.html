Automorphism Groups: Smallest Degree of Each Group

Dimension 1. For each automorphism group with a map in the database, the smallest degree of a map whose automorphism group is exactly that group, or open if there is none yet. For polynomials over ℚ the automorphism groups are completely classified ({{ polynomial_automorphism_citation | safe }}; see Mathematical Background), so that column gives the smallest possible degree, or none if no polynomial has that group. Groups are named as in GAP: Dn is dihedral of order 2n (D3 is written S3).
