Small Height Ratio

Dimension 1, degree 2 non-polynomial maps over ℚ

For a map f and a point P that is not preperiodic, the height ratio is ĥf(P) / hM(f): the canonical height of P divided by a height of f on moduli space, here the largest height of the fixed point multiplier invariants σ1, …, σd+1. Each row gives the rational point with the smallest ratio known for that map, with the map written in the coordinates of that point.
